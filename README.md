# 💼 Portfólio Pessoal

Portfólio desenvolvido para apresentar minhas habilidades, projetos e informações profissionais como estudante de Técnico em Informática.

## 📖 Sobre o projeto

Este projeto foi desenvolvido utilizando **HTML5**, **CSS3** e **JavaScript**, com o objetivo de reunir meus principais projetos, tecnologias, informações de contato e apresentar minha trajetória na área de Tecnologia.

O site possui um design moderno, responsivo e uma navegação intuitiva, permitindo que recrutadores e visitantes conheçam minhas habilidades e projetos desenvolvidos durante o curso.

## ✨ Funcionalidades

- Apresentação pessoal
- Seção "Sobre Mim"
- Listagem de habilidades (Skills)
- Informações sobre idiomas
- Portfólio de projetos
- Informações para contato
- Layout responsivo
- Interface moderna com animações

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 🎯 Objetivo

Desenvolver um portfólio online para apresentar meus projetos, habilidades e evolução como desenvolvedora, facilitando a divulgação do meu trabalho para recrutadores e profissionais da área de Tecnologia.
